# samples



# 声明 / Statement

本示例仓库中的所有源码注释均采用英文格式，以确保代码在不同平台、编译器和开发环境中的兼容性与一致性，同时便于国际开发者阅读与维护。

All source code comments in this sample repository are written exclusively in English to ensure compatibility and consistency across different platforms, compilers, and development environments, as well as to facilitate reading and maintenance by international developers.



每个示例的说明文档均采用中英文双语格式，其中中文和英文内容在信息上保持一致，旨在同时服务中文开发者与全球技术社区。

The documentation for each sample is provided in both English and Chinese (bilingual format), with the English and Chinese versions being informationally equivalent, aiming to serve both Chinese-speaking developers and the global technical community.



每个示例的根目录必须包含README文件， README文件的内容必须按照SAMPLE_README_TEMPLATE编写。

The root directory of each sample must contain a README file, and the contents of the README file must be written according to the SAMPLE_README_TEPLATE format.
